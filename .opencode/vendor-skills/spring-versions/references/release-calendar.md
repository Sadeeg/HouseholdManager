## Monthly Release Pattern

Spring follows a predictable monthly cadence:

- **Patch releases**: Monthly for all supported lines (usually mid-month)
- **Milestone releases**: Monthly during development of next minor/major
- **RC releases**: ~1 month before GA
- **GA releases**: May and November for new minor/major versions

## Keeping This Skill Current

This skill contains point-in-time version data that becomes stale. To verify:

1. Check [Spring Initializr](https://start.spring.io) — it always shows the latest Boot GA
2. Check `https://calendar.spring.io/ical` for planned dates
3. Check GitHub releases pages for each project

When updating this skill, update:
- `SKILL.md` "Current Latest Versions" table
- `SKILL.md` "Last updated" date in the overview
- `SKILL.md` dependency declaration version numbers in code examples
- This file's "Upcoming Planned Releases" section
